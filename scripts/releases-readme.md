# Ответошная — установка и обновления

Здесь лежат только установочные файлы программы «Ответошная» (ГКБ №24). Кода и данных здесь нет.

- **Mac:** [скачать Otvetoshnaya.dmg](https://github.com/hellatarantella/otvetoshnaya-releases/raw/main/Otvetoshnaya.dmg)
- **Windows:** [скачать Otvetoshnaya_setup.exe](https://github.com/hellatarantella/otvetoshnaya-releases/raw/main/Otvetoshnaya_setup.exe)

Установленная программа сама проверяет `latest.json` здесь и предлагает обновиться.
Каждое обновление подписано ключом — неподписанное программа не установит.
