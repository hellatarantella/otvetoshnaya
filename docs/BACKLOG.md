# Доработки «Ответошной»

Правило: перед каждым выпуском смотреть этот список и брать в релиз всё, что подходит по объёму и важности.
Выпуск только после `tests/run-all.sh`; после выпуска — сверка на настоящих отчётах.

## Сделано в 0.2.52
- Обжалование и письмо в этический комитет — в программе, без онлайн-сервиса: разбор по основаниям площадок с цитатами, утверждённая схема, короткая версия до 450 знаков, подсказка для формы площадки
- «Написать спасибо» и «Ответить на вопрос» — в программе по шаблонам и базе ответов
- Встроенная модель: правила из базы обучения (схема жалобы, смешанный отзыв, «сотрудники»)
- «База ответов»: загрузка базы обучения (JSON) — как ваши правки, без дублей

## Сделано в 0.2.51
- «Не отвечаем» и реклама — в «Нужна проверка», а не в «Позитив»
- Отзыв Google/2ГИС не заводится второй раз (служебная строка автора, поиск двойника по тексту)
- Новая неделя: если Google ответил с ошибкой, но неделю сменил — данные вносятся сразу; снимок закрытой недели для презентаций
- «Негатив»: неделя без негатива номер не тратит
- Сбор с первого раза: окно почты/Google ждём до 60 с и повторяем само; сторож — зависший сбор завершается сам и пишет шаг
- Презентация недели в программе: цифры из отчёта со сверкой, шаблон 1:1, фото с кадрированием, предложения на подтверждение, самопроверка вёрстки, PDF и PPTX

## В работе / ближайшее
- Отделение и ФИО врача в отчёте — строго по списку сотрудников текущего месяца (штатное подразделение), а не по тексту отзыва: Трифонова Н.В. попала в «Гинекологию» вместо СКП (22.10). Многопрофильное — по специальности
- Инциденты: счётчик на вкладке считает и закрытые, нужно только открытые
- Инциденты: кнопку «Ответ дан» нельзя отжать; при сборе состояние «дан / не дан» не обновляется с площадки (ответ удалён на площадке, а программа пишет «Ответ на площадке есть»), нужно сверять с площадкой при каждом сборе в обе стороны
- Публикация: ушёл ответ, не соответствующий отзыву (22.10). Перед публикацией сверять, что ответ относится именно к этому отзыву (имя автора, врач, тон), иначе не публиковать
- Смешанные отзывы (благодарность + жалоба): не считать просто позитивом, ставить «Нужна проверка» и тревогу; ответ отвечает на обе части
- «Тупой исполнитель» для скрипта Google: скрипт только пишет ячейки, вся логика в программе (больше не трогать скрипт)

## Важная доработка (большая)
- Обучение на правках: пары «было → стало» из «Базы ответов» → правила, которые генератор и модель применяют сами (что вы убираете — больше не предлагать)
- Самопроверка выпусков в бою: первый сбор после обновления в пробном режиме со сравнением со старой версией и откатом в один клик
- ИИ контент-анализа внутри программы: разбор каждого отзыва на части (благодарность кому/за что, жалоба на что, отделение, врачи, вопрос, просьба), смешанный тон, тема; ответ строится по этому разбору, очень вариативно (база её ответов, перестановки, свои формулировки), с проверкой «ответ соответствует отзыву» до публикации. Спроектировать до реализации, показать ей проект
- Загрузка своих ответов (файл или вставка) в программу: генератор дообучается на них и тасует, чтобы ответы были разными
- Генератор ответов учится: на вашей правке (пары «было → стало»), на новых отзывах, выводит правила из исправлений; персонализация по людям и отделениям; разнообразие ответов
