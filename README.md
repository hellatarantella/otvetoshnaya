# Ответошная

Программа для работы с отзывами ГКБ №24: тот же интерфейс, что у онлайн-сервиса, но всё работает
на компьютере пользователя.

- `web/page.html` — страница (одна и та же для онлайн-сервиса и программы)
- `web/runtime.js` — среда программы: хранилище, загрузки, фото, обновления, перенос данных
- `src-tauri/` — ядро на Tauri 2 (Rust): зашифрованный файл данных (AES-256-GCM, ключ в связке ключей ОС),
  запрет перехода окна на чужие сайты, строгая политика безопасности окна, подписанные обновления

Данные пользователя в репозиторий не попадают никогда.

Страница берётся из онлайн-сервиса через `python3 scripts/sync-page.py <страница> web/page.html` — без идентификаторов Google-файлов и задач.

Сборка и выпуск версий — в открытом репозитории otvetoshnaya-releases (там только установочные файлы). Код отсюда он берёт по ключу только для чтения.
